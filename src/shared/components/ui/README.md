# Componentes Primitivos (ui - Minúscula)

Esta carpeta contiene componentes primitivos e independientes basados en **shadcn/ui** y **Radix UI** (Átomos).

## Convención

1. **Nombres en Minúscula/CamelCase:** Los archivos y carpetas de esta sección siguen la estructura por defecto de shadcn/ui.
2. **Propósito:** Alojar componentes reutilizables de bajo nivel que actúan como ladrillos básicos de construcción (ej. botones base, inputs, sheets, dialogs, dropdowns, etc.).
3. **Mantenibilidad:** Si agregas componentes de shadcn, instálalos/creálos en este directorio para mantener la consistencia con las herramientas CLI de shadcn.

---
*Para componentes compuestos específicos de la aplicación (moléculas/organismos), utiliza la carpeta vecina `/src/shared/components/UI/`.*
